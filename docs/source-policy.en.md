# Source and Verification Policy

**Language:** English (current) · [中文](source-policy.md)

This repository treats public projects, technical articles, and social discussions as either leads or evidence. Runnable implementations belong in category pages; opinions and discussions belong in `research/sources.en.md`. Each record should retain the original link, author or organization, retrieval date, license when available, and evidence strength.

The catalog does not represent quality, security, production readiness, or third-party license suitability. Open the original source and review its code, tests, data claims, and license scope before use.

New code and documentation in this repository use [MIT](../LICENSE). Linked third-party projects retain their own licenses. `Jev`, `System One`, and `TypeSafe AI` are product or organization names used according to their public sources; this repository does not claim affiliation or endorsement.
