# 金融与贸易

**语言 / Language:** 中文（当前） · [English](../finance-trading.md)

对于 Jev 做出交易、投资或市场判断决策的程序，请使用此类别。

## 提交格式
```md
- [Name](URL) - Industry: one-sentence description of the Jev use case.
```
## 条目

- [Jevinik](https://github.com/unicodeveloper/jevocks) - 股票决策：通过 Valyu 收集实时市场证据并询问 Jev 股票是否可能在未来 30 天内走高的终端。
- [jev_stock](https://github.com/sosopop/jev_stock) - 短期预测：实验性港股框架，将结构化市场状态转变为价格方向的 Jev 决策，并带有第一个交易日的回测脚本。
- [jev-trade](https://github.com/aowang-ai/jev-trade) - 加密货币交易：要求 Jev 每轮选择在超流动性市场上做多或做空，下订单，并在许多资产上运行相同的循环。
- [Jev X Sentiment Analysis](https://github.com/brainstormity/Jev-X-Sentiment-Analysis) - 加密货币决策支持：通过统计预处理和 SQLite 重复数据删除，每个请求摄取 50-1,000 条推文，然后让 Jev 将幸存的证据转化为包含入场范围、止损和目标的决策卡，而不执行交易。
