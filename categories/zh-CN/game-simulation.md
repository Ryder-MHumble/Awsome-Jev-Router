# 游戏与模拟

**语言 / Language:** 中文（当前） · [English](../game-simulation.md)

使用此类别在游戏、模拟或交互式环境中做出决策。

## 提交格式
```md
- [Name](URL) - Industry: one-sentence description of the Jev use case.
```
## 条目

- [typesafe-mario](https://github.com/fhshaik/typesafe-mario) - 游戏：TypeSafe/Jev 代理在结构化模拟器状态下玩超级马里奥兄弟，从模拟器衍生的功能中选择每个动作。
- [jev-drone](https://github.com/RomanSlack/jev-drone) - 机器人模拟：MuJoCo 中仅配备摄像头的自主无人机，将 Jev 判断模型置于 2.5 Hz 的控制回路中。
- [tsai-sc](https://github.com/phyous/tsai-sc) - 游戏：通过键盘和鼠标驱动原始星际争霸共享软件，并记录每个决策的 Jev 动作概率。
- [jev-plays-pokemon](https://github.com/milanboers/jev-plays-pokemon) - 游戏：将 Pokémon Red 游戏状态读取为文本，每轮回答键入的问题，并让确定性代码将答案转化为动作。
- [typesafe-jev-drone-demo](https://github.com/kxzk/typesafe-jev-drone-demo) - 模拟：带有 Python 后端的 Three.js 无人机模拟器，Jev 在其中驱动导航决策。
- [typesafe-playground](https://github.com/kavehmz/typesafe-playground) - 互动游乐场：小型 Jev 实验，将决策显示在屏幕上，从路由支持消息到在 3D 世界中驾驶汽车。
- [PlayJev](https://github.com/OmniJev/PlayJev) - 游戏：开放 0.8B 视觉语言模型，可读取一个 448 px 游戏帧，返回游戏在一次前向传递中列出的移动的概率，无需生成文本，并将其低置信度步骤交给搜索程序，涵盖十个浏览器游戏。
- [jev-plays-pokemon-red](https://github.com/valentynkit/jev-plays-pokemon-red) - 游戏：PyBoy 上的 Pokemon Red，其中确定性代码拥有路线和算术，Jev 仅在分支处进行选择，每个战斗回合的微弱预测均由 Brier 针对 RAM 状态进行评分。
- [jev-reflex-autonomy-lab](https://github.com/khordoo/jev-reflex-autonomy-lab) - 无人机自主：一个多无人机实验室，Jev 提供反射决策，并有一个可选的较慢策略层指导它们。
- [Soupbase](https://github.com/spoonnotfound/soupbase) - 游戏：使用 Jev `Choice` 判断来回答横向思维谜题并评估提出的解决方案，应用程序代码需要支持的事实、连贯的解释和足够的信心，然后才能将谜题标记为已解决。
